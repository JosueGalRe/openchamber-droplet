@AGENTS.md

OpenChamber is a Droplet for Droppy, built with DroppyKit. AGENTS.md above is the brief: the build loop, the rules a droplet has to follow, and where the SDK's guides and sources are on this disk. The DroppyKit MCP server in `.mcp.json` gives you `droppykit_build`, `droppykit_validate`, `droppykit_shots` (the pictures of every surface, inline) and `droppykit_install` (into Droppy Playground); use the shots after every visual change, because you cannot see the harness window. Never make the droplet's icon: Jordy designs every Store droplet's icon, so leave the placeholder `Openchamber.icon` as it is. Run `droppykit agent --force` to regenerate these files.

Shelf widget style, in short: pad once with `context.contentInsets`; alone on a notched Mac or the camera island wrap the header row around the camera through `ShelfWidgetNotchWrapTraits` and `context.notchWrap`, never offsetting it yourself; on the camera island (`notchGeometry.cutout == .cameraIsland`) the compact row is the 31pt pill's height, so size to `DroppyLiveActivityMetrics.rowHeight(on:)`; every control is `DroppyWashCircleButtonStyle` or `DroppyWashPillButtonStyle` (34pt alone, 28pt paired or beside the camera, 24pt in a list row, `.neutral` except the one action the widget is for); the droplet's icon follows the user's icon style with no code. AGENTS.md has the details.
